## 1. Veri Tipleri (Data Types)

Python'da her verinin bir tipi vardır ve bellekte farklı türlerde saklanır. Bu tipler verinin ne olduğunu anlamamızı kolaylaştırır. Örneğin bir veri sayısal(numeric) değilse onunla matematik işlemleri yapamayız. Python'da bazı kodlama dilleri gibi bir değişkeni tanımlarken, **Dinamik tipleme (dynamic typing)** özelliği sayesinde  veri tipini önceden belirlememize gerek kalmaz. Değişkenin tipi, atanan değere göre Python tarafından otomatik olarak belirlenir.

### 1.1. Sayısal Tipler (Numeric Types)

* **`int` (Integer):** Tam sayıları tutar. Pozitif, negatif veya sıfır. 
* **`float` (Floating Point):** Ondalıklı sayıları tutar.**ÖNEMLİ**: Python'da ondalık ayıracı olarak **nokta (.)** kullanılır.
* **`complex` :** Gerçek ve sanal kısımdan oluşan karmaşık sayılardır. **`j`** harfi kullanılır.

```python
kisi_sayisi = 120            # int
sinav_notu = 67.5          # float
sinav_notu2 = 80.0          # float
karmasik_sayi = 3 + 4j     # complex


print(type(kisi_sayisi))        # Çıktı: <class 'int'>
print(type(sinav_notu))   # Çıktı: <class 'float'>
print(type(karmasik_sayi)) # Çıktı: <class 'complex'>
```

### 1.2. Metin Tipi (String - `str`)

Metinleri saklamak için kullanılır. Tek tırnak (`'...'`) veya çift tırnak (`"..."`) içine yazılır. 

* String ifadeleri **immutable** yani değiştirilemezdir. Metnin ortasında tek bir karakteri bile doğrudan değiştirme şansımız yoktur. Değişiklik yapmak için yeni bir string oluşturmamız gerekir
* Metnin her karakterinin `0`'dan başlayan bir indeks numarası vardır.

```python
kulup_adi = "ytuyoda"

print(kulup_adi[2])     # Üçüncü karakter -> Çıktı: u
print(len(kulup_adi)).  # Karakter sayısını verir -> Çıktı: 7
```

---

### 1.3. Mantıksal Tip (Boolean -  `bool`)

Sadece **`True`** ve **`False`** değerlerini alabilir. Baş harfleri mutlaka büyük yazılmalıdır. Genellikle karşılaştırma ifadelerinde karşımıza çıkan mantıksal tip koşul ifadelerinin temelini oluşturur.

```python
dersten_gecti = True
ort_yetersiz = 30 < 80  # Karşılaştırma sonucu False döner

print(dersten_gecti)         # Çıktı: True
print(ort_yetersiz)          # Çıktı: False
print(type(dersten_gecti))     # Çıktı: <class 'bool'>
```

### 1.4. Koleksiyon Tipleri (Birden Fazla Veri Tutan Yapılar)

#### Liste (`list`)
Köşeli parantez `[]` ile tanımlanır. **Mutable** yani değiştirilebilir bir yapıdadır, sıralıdır. İçerisinde farklı veri tipi tutmaya, aynı elemanın tekrar etmesine izin verir.

```python
sensorler = ["GPS", "Barometre", "Pusula"]
sensorler.append("Lidar")  # Listenin sonuna yeni eleman ekler
sensorler[0] = "RTK GPS"   # 0. indeksteki elemanı günceller

print(sensorler)           # Çıktı: ['RTK GPS', 'Barometre', 'Pusula', 'Lidar']
```

#### Demet (`tuple`)
Normal parantez `()` ile tanımlanır. Listeler gibi tekrar eden elemanlara izin verir fakat **immutable**, değiştirilemez bir yapıdır sıralıdır. Program boyunca sabit kalması gereken veriler (örneğin koordinatlar) için tercih edilir ve listelere göre daha hızlıdır.

```python
koordinat = (41.0082, 28.9784)
print(koordinat[0])        # Çıktı: 41.0082

# koordinat[0] = 42.0  --> Bu satır çalıştırılırsa TypeError hatası verir.
```

#### Küme (`set`)
Süslü parantez `{}` ile tanımlanır. Matematikteki kümeler gibi çalışır. Herhangi bir sıraya koyamayız **sırasızdırlar** bu yüzden liste, demet aksine indeksle erişilemezler. Tekrar eden sayıya izin verilmez otomatik olarak siler.

```python
frekanslar = {2.4, 5.8, 2.4, 915, 5.8}
print(frekanslar)          # Çıktı: {2.4, 5.8, 915} (tekrar edenler otomatik silinip elendi)
```

#### Sözlük (`dict` - Dictionary)
Süslü parantez `{}` içinde **`anahtar: değer` (`key: value`)** çiftleri halinde veri tutar. Anahtarlar benzersiz olmalıdır. Verilere indeks numarasıyla değil, anahtar ismiyle ulaşılır. 
* Normal değişkenler, tekil ve bağımsız veriler için daha uygundur. Örneğin : `pi = 3.14` 
* **`dict`** ise bir nesneye ait birden fazla özelliği **düzenli** tutmak için tercih edilir.

```python
iha_bilgi = {
    "model": "Quadcopter",
    "agirlik_kg": 2.4,
    "otonom": True
}

print(iha_bilgi["model"])      # Çıktı: Quadcopter
iha_bilgi["agirlik_kg"] = 2.6  # Mevcut değer güncellenebilir
```

### 1.5. Boş Değer (`NoneType`)

Bir değişkenin henüz bir değeri olmadığını veya bilerek olarak boş bırakıldığını ifade etmek için **`None`** kullanılır. `0`, `False` veya boş string (`""`) ile aynı şey değildir.

```python
son_hata = None
print(type(son_hata))  # Çıktı: <class 'NoneType'>
```

### 1.6. Tip Kontrolü ve Tip Dönüşümü (Type Casting)

* **`type()`:** Bir değişkenin hangi veri tipinde olduğunu kontrol eder.
* **Tip Dönüşümü:** Verileri `int()`, `float()`, `str()`, `list()` gibi fonksiyonlarla birbirine dönüştürebiliriz. Özellikle kullanıcıdan `input()` ile alınan veriler her zaman `str` geldiği için matematiksel işlem öncesi sayıya çevrilmeleri gerekir.

```python
girilen_hiz = "15"             # str
hiz_sayi = int(girilen_hiz)    # int'e dönüştürüldü

print(hiz_sayi + 5)            # Çıktı: 20
print(float(hiz_sayi))         # Çıktı: 15.0
```

## 2. Koşul İfadeleri (Conditionals)

Koşul ifadeleri, programın belirli durumlara göre **karar vermesini** ve verdiği bu karara göre farklı kod bloklarını çalıştırmasını sağlar. Temelinde `bool` (`True` veya `False`) mantığı yatar eğer koşul doğruysa ilgili blok çalışır, yanlışsa atlanır.

**Önemli!! (Girinti / Indentation):** Python'da kod bloklarını ayırmak için süslü parantez `{}` kullanılmaz. Bunun yerine koşul satırının sonuna iki nokta üst üste (`:`) konur ve alt satırdaki kodlar **4 boşluk (1 Tab)** içeriden yazılır. Girinti hatalı olursa Python `IndentationError` verir.

---

### 2.1. Karşılaştırma Operatörleri (Comparison Operators)

Koşul oluştururken değerleri birbiriyle karşılaştırmak için kullanılır ve sonuç olarak her zaman `True` ya da `False` döndürür.

| Operatör | Anlamı | Örnek | Sonuç |
| :--- | :--- | :--- | :--- |
| **`==`** | Eşit mi? | `5 == 5` | `True` |
| **`!=`** | Eşit değil mi? | `5 != 3` | `True` |
| **`>`** | Büyük mü? | `10 > 20` | `False` |
| **`<`** | Küçük mü? | `10 < 20` | `True` |
| **`>=`** | Büyük veya eşit mi? | `15 >= 15` | `True` |
| **`<=`** | Küçük veya eşit mi? | `12 <= 10` | `False` |

* **Önemli!!** Tek eşittir (`=`) değişkene **değer atamak** için, çift eşittir (`==`) ise **eşitlik kontrolü** yapmak için kullanılır.

---

### 2.2. `if`, `elif` ve `else` Yapısı

* **`if` (Eğer):** İlk kontrol edilen koşuldur. Sonuç `True` ise altındaki blok çalışır.
* **`elif` (Değilse eğer):** İlk `if` koşulu sağlanmadığında yeni bir koşul kontrol etmek için kullanılır. İstenildiği kadar `elif` eklenebilir.
* **`else` (Hiçbiri değilse):** Yukarıdaki koşulların hiçbiri sağlanmadığında çalışacak son bloktur. Yanına koşul yazılmaz.

Python koşulları yukarıdan aşağıya doğru okur ve **doğru olan ilk bloğu** çalıştırıp diğerlerini kontrol etmeden çıkar.

```python
batarya = 35

if batarya >= 80:
    print("Batarya dolu, göreve başlanabilir.")
elif batarya >= 20:
    print("Batarya orta seviyede, uçuşa dikkatli devam et.")
else:
    print("Kritik batarya! Eve dönüş (RTL) başlatılıyor.")

# Çıktı: Batarya orta seviyede, uçuşa dikkatli devam et.
```

---

### 2.3. Mantıksal Operatörler (Logical Operators)

Birden fazla koşulu tek bir `if` satırında birleştirmek için kullanılır:

* **`and` (Ve):** Tüm koşulların `True` olması gerekir. Biri bile `False` olursa sonuç `False` döner.
* **`or` (Veya):** Koşullardan en az birinin `True` olması yeterlidir.
* **`not` (Değil):** Koşulun sonucunu tersine çevirir (`True` ise `False`, `False` ise `True` yapar).

```python
gps_bagli = True
ruzgar_hizi = 12
acil_durum = False

if gps_bagli and ruzgar_hizi < 25:
    print("Uçuş koşulları uygun.")

if not acil_durum:
    print("Sistem normal çalışıyor.")

# Çıktı:
# Uçuş koşulları uygun.
# Sistem normal çalışıyor.
```

---

### 2.4. İç İçe Koşullar (Nested `if`)

Bir koşul sağlandıktan sonra, o bloğun içinde ikinci bir kontrol daha yapmak gerektiğinde iç içe `if` yapıları kullanılır.

```python
motor_aktif = True
irtifa = 50

if motor_aktif:
    if irtifa > 0:
        print("Araç havada.")
    else:
        print("Motorlar çalışıyor, araç yerde.")
else:
    print("Motorlar kapalı.")

# Çıktı: Araç havada.
```

## 3. Döngüler (Loops)

Döngüler, aynı veya benzer bir işlemi kodu tekrar tekrar yazmadan **belirli bir sayıda** ya da **bir koşul sağlandığı sürece** otomatik olarak çalıştırmak için kullanılır. Koşul ifadelerinde olduğu gibi döngü satırının sonuna `:` konur ve döngünün içine girecek kodlar **4 boşluk (1 Tab)** içeriden yazılır.

---

### 3.1. `for` Döngüsü ve `range()` Fonksiyonu

`for` döngüsü genellikle tekrar sayısı bilindiğinde veya bir koleksiyonun (`list`, `tuple`, `str`, `dict` vb.) elemanları üzerinde tek tek gezinmek istendiğinde kullanılır.

```python
sensorler = ["GPS", "Barometre", "Pusula", "Lidar"]

for sensor in sensorler:
    print("Kontrol ediliyor:", sensor)

# Çıktı:
# Kontrol ediliyor: GPS
# Kontrol ediliyor: Barometre
# Kontrol ediliyor: Pusula
# Kontrol ediliyor: Lidar
```

#### `range()` Fonksiyonu
Belirli bir sayı aralığında döngü kurmak için kullanılır. `range(baslangic, bitis, artis)` şeklinde çalışır; **bitiş değeri dahil edilmez**.

```python
# 0'dan 5'e kadar (5 hariç)
for i in range(5):
    print(i)  # Çıktı: 0, 1, 2, 3, 4

# 2'den 10'a kadar 2'şer artarak
for sayi in range(2, 10, 2):
    print(sayi)  # Çıktı: 2, 4, 6, 8
```

---

### 3.2. `while` Döngüsü

`while` döngüsü, belirtilen koşul **`True` olduğu sürece** çalışmaya devam eder. Tekrar sayısının önceden net olmadığı, bir şartın gerçekleşmesine bağlı durumlarda tercih edilir.

* **Dikkat (Sonsuz Döngü):** Döngü içinde koşulu bir noktada `False` yapacak bir güncelleme (örneğin sayacı artırmak veya azaltmak) yapılmazsa döngü sonsuza kadar çalışır.

```python
batarya = 100

while batarya > 20:
    print("Uçuş devam ediyor. Kalan batarya:", batarya)
    batarya -= 30  # Her turda bataryayı 30 azaltır

print("Batarya kritik seviyede, iniş yapılıyor.")

# Çıktı:
# Uçuş devam ediyor. Kalan batarya: 100
# Uçuş devam ediyor. Kalan batarya: 70
# Uçuş devam ediyor. Kalan batarya: 40
# Batarya kritik seviyede, iniş yapılıyor.
```

---

### 3.3. Döngü Kontrol İfadeleri (`break` ve `continue`)

Döngünün normal akışını değiştirmek için kullanılır:

* **`break`:** Döngüyü o anda **tamamen sonlandırır** ve döngüden dışarı çıkar.
* **`continue`:** Sadece **o anki turu atlar**, alttaki satırları çalıştırmadan döngünün bir sonraki adımına geçer.

```python
# break örneği: Aranan durum bulununca döngüyü durdurur
for irtifa in range(10, 60, 10):
    if irtifa == 30:
        print("Hedef irtifaya ulaşıldı, tırmanış durduruluyor.")
        break
    print("Mevcut irtifa:", irtifa)

# Çıktı:
# Mevcut irtifa: 10
# Mevcut irtifa: 20
# Hedef irtifaya ulaşıldı, tırmanış durduruluyor.
```

```python
# continue örneği: Sadece belirli bir adımı atlar
for i in range(1, 6):
    if i == 3:
        continue  # 3'ü yazdırmadan sonraki tura geçer
    print(i)

# Çıktı: 1, 2, 4, 5
```

---

### 3.4. `for` ve `while` Farkı

| Özellik | `for` Döngüsü | `while` Döngüsü |
| :--- | :--- | :--- |
| **Kullanım Amacı** | Eleman sayısı veya tekrar sayısı belliyse | Bir koşul sağlandığı sürece devam edilecekse |
| **İlerleme** | Koleksiyon veya `range()` boyunca otomatik ilerler | Koşulu değiştirecek adımı manuel yazmak gerekir |
| **Sonsuz Döngü Riski** | Çok düşüktür | Koşul güncellenmezse yüksektir |

## 4. Fonksiyonlar (Functions)

Fonksiyonlar, belirli bir görevi yerine getiren ve ihtiyaç duyulduğunda tekrar tekrar çağrılabilen **yeniden kullanılabilir kod bloklarıdır**. Aynı kodu programın farklı yerlerinde defalarca yazmak yerine bir kez fonksiyon olarak tanımlar, gerektiğinde sadece adını çağırırız. Bu hem kod tekrarını önler hem de programın okunmasını kolaylaştırır.

---

### 4.1. Fonksiyon Tanımlama ve Çağırma (`def`)

Python'da fonksiyonlar **`def`** anahtar kelimesi ile tanımlanır. Fonksiyonu tanımlamak tek başına onu çalıştırmaz; çalışması için adıyla **çağırmak** gerekir.

```python
def ucus_baslat():
    print("Sistem kontrolleri yapılıyor...")
    print("Motorlar aktif, kalkışa hazır.")

# Fonksiyonu çağırma
ucus_baslat()

# Çıktı:
# Sistem kontrolleri yapılıyor...
# Motorlar aktif, kalkışa hazır.
```

---

### 4.2. Parametre ve Argüman Kullanımı

Fonksiyonlara dışarıdan veri göndermek için parantez içine **parametre** yazılır. Fonksiyonu çağırırken gönderdiğimiz gerçek değerlere ise **argüman** denir.

* **Varsayılan Parametre (Default Parameter):** Bir parametreye baştan bir değer atanabilir. Fonksiyon çağrılırken o değer gönderilmezse varsayılan değer kullanılır.

```python
def irtifa_ayarla(hedef_irtifa, mod="Otonom"):
    print(f"{mod} modda {hedef_irtifa} metreye tırmanılıyor.")

irtifa_ayarla(50)               # Çıktı: Otonom modda 50 metreye tırmanılıyor.
irtifa_ayarla(100, "Manuel")    # Çıktı: Manuel modda 100 metreye tırmanılıyor.
```

---

### 4.3. `return` İfadesi (`return` vs `print` Farkı)

* **`print()`** sadece sonucu ekrana yazdırır; o değeri programın başka bir yerinde tekrar kullanamayız.
* **`return`** ise fonksiyonun hesapladığı sonucu dışarıya **geri döndürür**. Böylece o sonucu bir değişkene atayabilir veya başka matematiksel işlemlerde kullanabiliriz. `return` satırı çalıştığında fonksiyon sonlanır.

```python
def kalan_mesafe(hiz, sure):
    mesafe = hiz * sure
    return mesafe

ucus_mesafesi = kalan_mesafe(15, 20)  # Dönen değer değişkene atanır
print("Gidilen mesafe:", ucus_mesafesi, "metre")

# Çıktı: Gidilen mesafe: 300 metre
```

---

### 4.4. Değişken Kapsamı (Local ve Global Değişkenler)

* **Yerel (Local) Değişken:** Bir fonksiyonun içinde tanımlanır ve sadece o fonksiyonun içinde geçerlidir; dışarıdan erişilemez.
* **Global Değişken:** Fonksiyonların dışında tanımlanır ve programın her yerinden okunabilir.

```python
arac_tipi = "Quadcopter"  # Global değişken

def bilgi_goster():
    pilot = "İlayda"      # Local değişken (sadece bu fonksiyon içinde geçerli)
    print(arac_tipi, "-", pilot)

bilgi_goster()            # Çıktı: Quadcopter - İlayda
# print(pilot)            --> NameError hatası verir, çünkü 'pilot' yerel değişkendir.
```

## 5. Sınıflar (Classes)

**Sınıf (`class`)**, ortak özelliklere ve davranışlara sahip nesneler üretmek için kullanılır. Bu şablondan üretilen her bir somut örneğe ise **nesne (instance)** deriz.

### Temel Kavramlar

* **`class`**: Yeni bir sınıf tanımlamak için kullanılan anahtar kelimedir.
* **`__init__` **: Sınıftan yeni bir nesne oluşturulduğu anda otomatik olarak çalışan kurulum fonksiyonudur. Nesnenin başlangıç özellikleri burada atanır.
* **`self`**: Sınıfın içinde, o an oluşturulan veya üzerinde işlem yapılan nesnenin kendisini temsil eder. Nesneye ait değişkenlere ve metotlara erişmek için ilk parametre olarak yazılır.
* **Özellikler (Attributes)**: Nesnenin sahip olduğu verilerdir, örneğin `marka`, `model`, `hiz` vs.
* **Metotlar (Methods)**: Sınıfın içinde `def` ile tanımlanan ve o nesnenin yapabileceği işlemleri belirleyen fonksiyonlardır.

### Örnek Kullanım

```python
class Araba:
    # Nesne oluşturulduğunda otomatik çalışan kurulum metodu
    def __init__(self, marka, model, hiz=0):
        self.marka = marka  # Nesnenin marka özelliği
        self.model = model  # Nesnenin model özelliği
        self.hiz = hiz      # Nesnenin başlangıç hızı

    # Nesnenin hızını artıran metot
    def hizlan(self, artis):
        self.hiz += artis
        print(f"{self.marka} {self.model} hızlandı. Güncel hız: {self.hiz} km/s")

    # Nesnenin bilgilerini gösteren metot
    def bilgi_goster(self):
        print(f"Araç: {self.marka} {self.model} | Hız: {self.hiz} km/s")


# Sınıftan nesne (örnek) oluşturma
araba1 = Araba("Toyota", "Corolla")

# Nesne metotlarını çağırma
araba1.hizlan(50)
araba1.bilgi_goster()
```

### Çıktı

```text
Toyota Corolla hızlandı. Güncel hız: 50 km/s
Araç: Toyota Corolla | Hız: 50 km/s
```
