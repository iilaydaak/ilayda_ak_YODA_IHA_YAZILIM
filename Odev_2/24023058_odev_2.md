# Ödev 2: Git, GitHub ve İHA Masterclass

## 1. Git ve GitHub Temel Kavramları
Bu süreçte versiyon kontrol sistemi olan Git ve GitHub üzerinde öğrendiğim temel kavramlar şunlardır:

* **Repository (Repo):** Proje dosyalarının ve değişiklik geçmişinin tutulduğu git deposudur.
* **Branch (Dal):** Ana projeyi bozmadan bağımsız çalışabilmek için oluşturulan çalışma alanıdır.
* **Commit:** Yapılan değişiklikleri açıklayarak bir mesajla beraber sisteme kaydetme şeklidir.
* **Push:** Bilgisayardaki yerel değişiklikleri GitHub'a yüklemektir.
* **Pull:** GitHub'daki güncel değişiklikleri bilgisayarımıza indirmektir.
* **Merge:** Farklı dallarda (branch) yapılan çalışmaları tek bir dalda birleştirme işlemidir.

**Örnek kullanım şekilleri**
Projeme yeni bir özellik ekleyeceğim zaman önce yeni bir dal açıp değişikliklerimi kaydederim:
```bash
git checkout -b yeni_ozellik
git add .
git commit -m "Yeni özellik eklendi"
git push
